Cloud-save workflow

Follow these steps in order. The patch works after the game has already downloaded the cloud save.

  1. Open Meccha Chameleon and stay on the main page. Do not join a match yet. Wait a few seconds so the cloud save finishes loading.
  2. Open the save folder. Press Win + R, paste the folder path below, then press Enter.
  3. Drag the real save into this site. Use the file inside SaveGames named cLeon_Default_*.sav.
  4. Edit values, then download the edited save. The edited download keeps the original filename.
  5. Replace the old file in SaveGames. Overwrite the original cLeon_Default_*.sav with the edited download.
  6. Go back to the game and force a save. Join as hunter and find at least one hider. This makes the game save the patched values.
