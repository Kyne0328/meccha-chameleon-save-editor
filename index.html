How to use

1. Find your save

Open this folder in Windows:

%LOCALAPPDATA%\Chameleon\Saved\SaveGames
2. Edit it here

Choose the .sav file, change the values, then download the edited file.

3. Use it in-game

Keep a backup, rename the edited file to the original save name, then replace the old file in the save folder.
