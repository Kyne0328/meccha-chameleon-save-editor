# 🦎 Meccha Chameleon Save Editor

Edit your Meccha Chameleon save file directly in your browser.

No install. No account. No upload. Open your save, change the values, and save directly back into the file in Chrome or Edge.

## 🚀 Use the app

👉 https://meccha-chameleon-save-editor.vercel.app/

## ✨ What you can edit

- ❤️ Likes received
- 🔎 Players found

## ✅ Recommended browser

Use **Chrome** or **Microsoft Edge** for direct saving.

Other browsers can still use the fallback upload/download method.

## 🕹️ How to use direct save

1. 🌐 Open Meccha Chameleon and stay on the main page.
2. 🌐 Open the app:

```text
https://meccha-chameleon-save-editor.vercel.app/
```

3. ⌨️ Press **Win + R**.
4. 📁 Paste this folder path:

```text
%LOCALAPPDATA%\Chameleon\Saved\SaveGames
```

5. 🦎 In the app, click **Open save directly**.
6. 📂 Select the file that starts with **cLeon_Default_** and ends with **.sav**.
7. ✏️ Change likes received or players found.
8. 🛟 Click **Download backup** to keep a copy of the original.
9. 💾 Click **Save directly**.
10. 🎯 In the game, join a match as hunter and find at least one hider so the game saves the patched values.

## 🧩 Fallback method

If direct save is not supported in your browser:

1. Drag the **cLeon_Default_*.sav** file onto the upload box.
2. Edit the values.
3. Click **Download edited save**.
4. Replace the file inside **SaveGames** with the downloaded file.
5. Join as hunter and find at least one hider.

## ⚠️ Notes

- 🔒 Your save is edited in your browser.
- 🛟 Keep a backup before replacing your save.
- ☁️ Staying on the main page lets the game finish cloud download first. After patching, finding a hider forces the game to save the patched local file.
